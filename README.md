# Project Management Tool

## Description
A React-based Project Management Tool that allows users to:

- Create tasks
- Add task descriptions
- Assign projects
- Set deadlines
- Mark tasks as completed
- Delete tasks

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3

## Features

- Task Creation
- Task Completion Tracking
- Deadline Management
- Project Organization
- Responsive UI

npm install
npm start
